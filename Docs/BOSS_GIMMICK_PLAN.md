# 보스 기믹 — 궁극기 컷인과 빈사 (기획안, 결정 대기)

> 작성: 2026-09-14 · 상태: **제안만 한 상태. 아래 "정해야 할 것" 세 가지를 고르기 전에는 구현하지 않는다.**
> 순서: 일반 몬스터 이미지 교체가 끝난 다음 작업.

처음 아이디어: 보스가 기믹에 성공하면(플레이어가 못 막으면) 궁극기 모션 연출이 나오고 플레이어가 빈사 또는 즉사한다.

## 확인한 현재 상태

- **2페이즈 보스 패턴 3개는 피하는 방법이 전부 다르다.** 내려찍기는 옆으로 한 걸음, 잿불 파도는 사이로 빠지기,
  재 폭발은 멀리 떨어지기(네 모서리). 기믹은 이 셋과 겹치지 않는 네 번째 답이어야 한다.
- **플레이어 체력은 게임 안에서 5다.** 프리팹 값은 3이지만 `Game.unity`가 5로 덮어쓴다. 재 폭발(3피해)을 한 번 맞으면 2가 남는다.
- **컷신 틀은 이미 있다.** 2페이즈 전환이 타임라인 연출이고, 시그널과 시그널이 안 왔을 때의 안전망이 있다
  (`Assets/Project/Scripts/Enemy/BossTransitionSequence.cs`). 궁극기 컷신도 같은 구조를 쓴다.
- **컷인 시스템은 이미 계획에 있다.** `PROJECT_CONTEXT.md` 09-09 방향표 3번(궁극기·보스 등장).
- **시간은 PauseGate만 만진다.** 컷신 중 게임을 멈추는 것도 PauseGate를 거친다.
- **함정 두 개**
  - `PlayerController.cs:371`이 매 프레임 무적 값을 대시 상태로 덮어쓴다. 컷신용 무적을 Health에 직접 걸면 다음 프레임에 사라진다.
  - `Health.cs:152`의 `TakeDamage`는 무적을 존중한다. 체력을 1로 만드는 경로가 따로 필요하다.

## 추천 기획: 저지 게이지 ("왕관이 타오른다")

이야기는 의식으로 잡는다. 플레이어가 보스 열쇠로 모은 **부러진 왕관**("반쪽이 어디론가 사라졌다")을 보스가 되찾아
자기 왕관을 완성하려 한다. 진행 아이템이 보스전과 이어진다.

| 단계 | 보스 | 플레이어 | 화면 |
|---|---|---|---|
| 발동 | 보스 체력 35%(2페이즈 한가운데)에서 한 번. 제자리에 멈춰 왕관을 들어 올린다 | — | 배너, 저지 게이지, 8초 타이머 |
| 시전(8초) | 피해가 체력 대신 게이지로 들어간다. 2초마다 잿불 파도를 쏜다 | 파도를 피하면서 계속 때린다(게이지 16) | |
| 성공 | 왕관이 깨지고 3초 경직 | 몰아친다 | 주인공 컷인(1초)과 히트스톱 |
| 실패 | 궁극기 컷인에 이어 방 전체 폭발 | 체력이 1로 떨어진다(이미 1이면 사망) | 보스 컷인(2.5초) |
| 실패 직후 | 2초간 공격하지 않고, 재 폭발 쿨타임이 처음부터 다시 돈다 | 1.5초 무적 | 빈사 연출 |

- **답은 "때려서 막는다"다.** 같은 페이즈의 재 폭발은 "멀어져라"라서, 도망과 돌진을 바꿔 가며 판단해야 한다.
- **숫자:** 평타만 치면 초당 약 3 피해(0.65초마다 2)라 게이지 16은 약 5.2초 걸린다. 8초 중 약 2.7초는 파도를 피하는 데 쓸 수 있다.
- **R을 아껴둘 이유가 생긴다.** R은 8 피해라 한 방에 게이지 절반이다.
- **시전 중에는 체력이 안 깎인다.** 한 방이 센 빌드도 기믹을 건너뛸 수 없다. `OnDamaged`에 적힌
  "마지막 한 대가 페이즈 전환을 시작해 버린" 것 같은 사망 순서 함정도 피한다.
- **한 판에 한 번이라 외울 수 있다.** 시간 기준으로 발동하면 느린 빌드만 여러 번 맞는다.
- 실패 직후 유예는 기존 `ultimateFirstDelay`와 같은 목적이다 — 컷신 직후 피할 수 없는 공격을 막는다.

## 빈사 vs 즉사

**추천: 체력을 1로 만들고, 이미 1이면 사망.**

- 보스는 약 17방 뒤에 있다. 처음 보는 기믹을 한 번 실패했다고 런 전체를 잃는 건 가혹하다.
- 이미 체력 1인 플레이어는 컷신에서 죽으니 "재가 된다" 장면은 그대로 산다. 결과 화면 문구 "재가 되었다"와도 맞다.
- 대안: 남은 게이지로 등급을 매긴다. 절반 넘게 남았을 때(거의 시도하지 않았을 때)만 즉사.
- 체력 1 경고(잿빛 화면 가장자리)는 보스 전용이 아니라 모든 피해에 쓰는 공통 연출로 만든다.

## 동영상 vs 타임라인 컷인

**추천: 2.5초 타임라인 컷인 + 일러스트 1~2장.**

| 시각 | 내용 |
|---|---|
| 0.0 | 게임이 멈추고, 위아래 검은 띠가 들어오고, 화면이 어두워진다 |
| 0.2 | 사선 띠에 보스 얼굴 클로즈업과 이름 "재의 길"이 밀려 들어온다 |
| 1.2 | 플래시와 함께 띠가 깨지고 게임 화면으로 돌아온다. 보스 궁극기 시트와 폭발 이펙트 |
| 1.7 | 명중: 히트스톱과 강한 흔들림, 체력 1 또는 사망 |
| 2.5 | 띠가 빠지고 조작이 돌아온다 |

- 전환 컷신과 같은 구조라 스크럽하면서 조정할 수 있다.
- 픽셀아트 화풍과 맞는다. 매 판 나오니까 짧아야 한다.
- 같은 컷인을 주인공 R과 보스 등장에도 다시 쓸 수 있어서 방향표 3번이 같이 끝난다.
- 스킬 이름 없이 "재의 길"만 띄운다. 이 세계에서 고유명은 보스 이름 하나뿐이라는 규칙 때문이다.
- 실제 영상을 쓰려면 VideoPlayer → RenderTexture → RawImage로, 게임을 멈춘 채 실시간으로 재생한다.
  첫 재생이 끊기지 않게 보스 방에 들어갈 때 `Prepare()`를 불러둔다(플레이 영상 분석에서 첫 사용 끊김이 이미 잡혔다).
  가장 어려운 건 픽셀아트 캐릭터와 화풍이 맞는 영상을 구하는 일이다.

## 다른 기믹 후보

- **봉인 기둥 4개**(네 모서리, 열쇠 4종과 연결): 괜찮은 대안. 남은 기둥 수로 벌칙 등급을 나눌 수 있지만, 기둥 오브젝트와 이동 동선을 따로 조정해야 한다.
- **안전지대에 서기:** 재 폭발의 모서리와 답이 같다. 비추천.
- **잡기 → 컷신:** 대시 회피와 답이 같다. 큰 공격이 하나 늘 뿐이다.

## 기획 정리

1. **한 줄 요약:** 2페이즈 중반에 한 번, 보스의 왕관 의식을 제한 시간 안에 때려서 막지 못하면 궁극기 컷인이 나오고 플레이어 체력이 1이 된다(이미 1이면 사망).
2. **접근 방식**
   - 보스에 시전 상태를 추가하고, 페이즈 전환처럼 한 번만 돌게 막는다.
   - 시전 중 피해는 게이지로 보낸다.
   - 컷인은 같은 타임라인·시그널·안전망 구조로 만든다.
   - PauseGate로 멈추고 타임라인은 실시간(unscaled)으로 재생한다.
3. **관련 스크립트**
   - `EnemyBoss.cs:521` 패턴 선택 — 기믹이 재 폭발보다 먼저
   - `EnemyBoss.cs:859` 피해 처리 — 피해를 게이지로 보냄
   - `BossTransitionSequence` — 컷신 틀
   - `PauseGate` — 멈춤과 히트스톱
   - `Health` — 체력을 1로 만드는 경로
   - `PlayerController` — 컷신 중 입력 잠금과 무적
   - `BossHealthBar` / `BossEncounter` — 게이지 표시와 연결
   - `CameraShake`

만드는 순서 제안: ① 기믹 규칙만(임시 UI + 디버그 패널 "기믹 직전으로" 버튼) → ② 컷인 시스템(빈 이미지로) → ③ 일러스트 끼우기.
방향표의 "이미지는 마지막에"와 같은 순서다.

3. 연출: 타임라인 컷인 / 실제 영상
