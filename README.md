# 재의 길 (Path of Ash)

> ## "타고 남은 것은 길뿐이다."

2D 탑다운 던전 슬래셔 로그라이크. 죽으면 언락도 성장도 남지 않고 처음부터 다시 시작한다.

메타 진행을 두지 않은 것은 분량을 줄이려는 타협이 아니라 설계 선택이다. 영구 강화가 없으면
반복 동기를 **아이템 시너지**가 전부 짊어지게 되고, 그래서 이 프로젝트의 기술적 중심은
전투 감각이 아니라 아이템 효과를 조합 가능한 형태로 설계하는 쪽에 있다.
